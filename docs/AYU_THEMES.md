# Ayu Running 四主题

更新：2026-10-22。

在训练记录的操作菜单中打开“生成日报”，在受保护的 Hub 页面选择黑绿、酒红、蓝白或紫橙，再点击“生成日报”。不指定主题的 API 请求仍默认黑绿。每份 HTML 内的“下载 PNG”导出同主题图片。

- 黑绿：重整的训练控制台，白色结论、绿色信号。
- 酒红：玫瑰白纸面，明显酒红标题、宋体运动手记。
- 蓝白：冷蓝白数据工作台，侧栏章节。
- 紫橙：淡紫与杏橙、运动票据与实线轮廓。

[四主题独立预览](https://coffaye.github.io/running_page/ayu-themes/) 使用同一份已核对的 2026-10-22 数据。预览不是活动 manifest 里的新增日报，不改变已有正式报告。

模板与提示词 Skill 在 [ayu-running-reports](https://github.com/coffaye/ayu-running-reports)，其 [使用文档](https://github.com/coffaye/ayu-running-reports/blob/main/AYU_RUNNING_GUIDE.md) 提供日报、周报、月报及主题提示词。线上生成与主题验证在 [ayu-running-hub](https://github.com/coffaye/ayu-running-hub) 维护。

历史报告不会因升级自动换主题；重新生成成功后，现有一份正式报告才更新，失败时保留旧报告。PNG 固定 2480px 宽、高度至少 3508px，内容多时只增高，不带页脚文字。
